# Monkey Business
Build a ridiculous primate-powered word empire.

## How to Play
- **Type:** Click the large button to type random characters.
- **Words:** Occasional words will appear, earning you bananas.
- **Shop:** Use bananas to buy monkeys and upgrades.
- **Monkeys:** They type for you automatically!

## Development
This is a static browser game.
- `index.html`: UI and layout
- `styles.css`: Game design and animations
- `script.js`: Game logic and persistence

## Deployment
Deployed via GitHub Pages.
1. Push to `main`.
2. Enable GitHub Pages in Repository Settings.
